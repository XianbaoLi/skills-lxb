# 示例：一轮完整循环（两种通道）

> 场景：第 2 轮。已锁定 3 项、待决 1 项、前沿 3 题。
> 有表单的平台走 ②A；无表单平台走 ②B。节奏完全一致。

## ① 交付前正文（一行）

`🔁 第 2 轮 · 前沿 3 题｜已锁定 3 · 待决 1`

## ②A 表单通道（Claude Code / Hermes）

**Q1 · 科研赋能**：为科研赋能，最先想到的落点？

- ① 文献知识库 / 科研信息管理 ——（用户已多次提到，推荐）
- ② STM 数据（谱 / 形貌）自动化
- ③ 科研流程 agent
- （Other 由 UI 自动附加）

**Q2 · 投入节奏**：每周可投入的学习 / 项目时间？

- ① 5–10 h/周（与已有画像一致，推荐）
- ② 10–20 h/周
- ③ 碎片化、不固定

**Q3（多选）· 近期目标**：接下来 3–6 个月要拿下什么？

- ① 实习插件做出成果（推荐）
- ② 打磨开源项目

- ④ 搭知识库

## ③ 提交后：写入 + 回执

> ✅ 本轮写入：落点=文献知识库（画像文件 + 记忆落点）；节奏=5–10h（与既有条目一致，未重复写）；目标=插件成果（记忆落点）。
> 重算前沿：新增「知识库形态」「插件验收标准」两题 → 第 3 轮。

## 常见错误对照

- ❌ 8 题挤一轮 → ✅ 拆两张、顺序发。
- ❌ 题干里写「请选①或②」 → ✅ 选项独立成列 / 成行。
- ❌ 互斥问题开多选（数据库引擎：PG/MySQL/…全勾）→ ✅ 单选。
- ❌ 手写 "(Recommended)" / "Other"（有 UI 的平台）→ ✅ 交给 UI 自动生成。
- ❌ 问「我的计划行不行？」→ ✅ 出收束清单，等确认。
