# Routed Blind Review Contract

Review the supplied translation unit in one review pass against the supplied
source. Batch-read the auxiliary source text, unit terms, anonymized candidate
files, and compact deterministic-findings summary. Open targeted PDF pages
only where visual authority is needed or extracted text is ambiguous. Do not
load the producer's conversation, model identity, general skill documentation,
tool transcript, successful compiler logs, or unrelated book material.

The published PDF is authoritative. The extracted text is only a searchable
aid. Evaluate each candidate independently for:

1. complete coverage and correct hierarchy;
2. source fidelity, including qualifications and formula-adjacent prose;
3. natural, precise Chinese;
4. terminology and symbol consistency;
5. LaTeX structure, references, figures, tables, footnotes, and lists.

Prioritize definitions, derivations, captions, conclusions, and anything named
by the deterministic findings. Do not repeat compilation or project-wide
audits that already passed.

Classify issues as `severe`, `ordinary`, or `stylistic`. A severe issue is a
material omission, mathematical or logical error, source reversal, broken
structure, wrong reference, or terminology error that changes meaning. State
whether repair is local or requires substantive retranslation.

Return only the requested structured review report. For comparative review,
score anonymized candidates using the same rubric and select a winner only
when the evidence supports one. Do not infer model identity or reward a
candidate for formatting that hides missing content.

Do not edit or retranslate the candidate, start a second review pass, or ask
another model to confirm the judgment. The controller decides whether one
bounded repair is needed from the compact issue list.
